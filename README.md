# 🚀 Crypto Telegram Bot

A Telegram bot that fetches real-time cryptocurrency data using the CoinGecko API.

## ✨ Features

- 🔍 Search cryptocurrency prices
- 📈 Real-time market data
- 💰 View coin prices in USD
- 📊 Market cap and 24h changes
- ⚡ Fast responses via Telegram
- 🌐 Powered by CoinGecko API
